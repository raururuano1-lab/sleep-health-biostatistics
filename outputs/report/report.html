A. Presentación de la base de datos

La base de datos seleccionada es Sleep Health and Lifestyle Dataset. Es una base relacionada con salud del sueño, hábitos de vida, actividad física, estrés, composición corporal e indicadores fisiológicos. Su utilidad para el trabajo radica en que permite estudiar un problema de interés sanitario: la relación entre el nivel de estrés percibido y la calidad del sueño.

La fuente utilizada corresponde a una base secundaria en formato CSV. El archivo se encuentra dentro de la misma carpeta del proyecto de RStudio; por esa razón, el código utiliza una ruta relativa y no una ubicación específica de la computadora.

# Lectura de la base desde la carpeta del RStudio Project.

B. Sujetos, unidad de análisis y variables

Los sujetos de estudio corresponden a personas adultas registradas en la base de datos. La unidad de análisis es cada participante individual, ya que cada fila contiene información independiente sobre características sociodemográficas, hábitos de vida, estrés, actividad física, indicadores fisiológicos y sueño.

La población representada puede interpretarse como adultos con diferentes ocupaciones y estilos de vida. Sin embargo, al tratarse de una base secundaria, no debe asumirse que la muestra representa a toda la población adulta. La generalización debe hacerse con prudencia, especialmente porque no se dispone de información completa sobre el proceso de muestreo original.

sleep_sel <- sleep %>%
  select(
    gender,
    age,
    sleep_duration,
    quality_of_sleep,
    physical_activity_level,
    stress_level,
    bmi_category,
    blood_pressure,
    heart_rate,
    daily_steps,
    sleep_disorder,
    occupation
  ) %>%
  mutate(
    # Recodificación preventiva:
    # Si la base tuviera valores vacíos o NA en sleep_disorder,
    # se interpretan como ausencia de trastorno reportado.
    sleep_disorder_clean = case_when(
      is.na(sleep_disorder) | trimws(sleep_disorder) == "" ~ "None",
      TRUE ~ sleep_disorder
    ),

    # Unificación de categorías equivalentes del IMC.
    bmi_category = case_when(
      bmi_category %in% c("Normal", "Normal Weight") ~ "Normal",
      TRUE ~ bmi_category
    )
  ) %>%
  separate(
    blood_pressure,
    into = c("systolic_bp", "diastolic_bp"),
    sep = "/",
    convert = TRUE,
    remove = FALSE
  ) %>%
  mutate(
    gender = factor(gender, levels = c("Female", "Male"),
                    labels = c("Mujer", "Hombre")),
    bmi_category = factor(bmi_category,
                          levels = c("Normal", "Overweight", "Obese"),
                          labels = c("Normal", "Sobrepeso", "Obesidad")),
    sleep_disorder_clean = factor(
      sleep_disorder_clean,
      levels = c("None", "Insomnia", "Sleep Apnea"),
      labels = c("Sin trastorno reportado", "Insomnio", "Apnea del sueño")
    ),
    occupation = as.factor(occupation)
  )

tabla_frecuencia <- function(datos, variable, nombre_variable) {
  datos %>%
    count({{ variable }}, name = "frecuencia") %>%
    mutate(
      porcentaje = round(frecuencia / sum(frecuencia) * 100, 2),
      variable = nombre_variable
    ) %>%
    rename(categoria = {{ variable }}) %>%
    mutate(categoria = as.character(categoria)) %>%
    select(variable, categoria, frecuencia, porcentaje)
}

Revisión de valores extremos

contar_outliers <- function(x) {
  q1 <- quantile(x, 0.25, na.rm = TRUE)
  q3 <- quantile(x, 0.75, na.rm = TRUE)
  riq <- q3 - q1
  limite_inferior <- q1 - 1.5 * riq
  limite_superior <- q3 + 1.5 * riq

  tibble(
    limite_inferior = limite_inferior,
    limite_superior = limite_superior,
    posibles_valores_extremos = sum(
      x < limite_inferior | x > limite_superior,
      na.rm = TRUE
    )
  )
}

D. Análisis descriptivo

El análisis descriptivo resume las características principales de la muestra. Para variables cuantitativas se calcularon media, mediana, desviación estándar, mínimo y máximo. Para variables cualitativas se calcularon frecuencias y porcentajes.

Variables cuantitativas

resumen_cuantitativo <- function(datos, variables) {
  datos %>%
    select(all_of(variables)) %>%
    pivot_longer(
      cols = everything(),
      names_to = "variable",
      values_to = "valor"
    ) %>%
    group_by(variable) %>%
    summarise(
      n = sum(!is.na(valor)),
      media = mean(valor, na.rm = TRUE),
      mediana = median(valor, na.rm = TRUE),
      desviacion_estandar = sd(valor, na.rm = TRUE),
      minimo = min(valor, na.rm = TRUE),
      maximo = max(valor, na.rm = TRUE),
      .groups = "drop"
    )
}

F. Relación con el diseño de investigación

La estructura de esta base corresponde a un diseño observacional, analítico y transversal. Es observacional porque el investigador no asigna exposiciones ni intervenciones; es analítico porque se evalúa la relación entre variables; y es transversal porque la medición de estrés, sueño, actividad física y demás características ocurre en un único momento para cada participante.

Este diseño es adecuado para describir la muestra y explorar asociaciones. No obstante, no permite establecer temporalidad. Por ejemplo, si se observa que las personas con más estrés tienen peor calidad del sueño, no se puede asegurar si el estrés precedió a la mala calidad del sueño o si dormir mal aumentó la percepción de estrés. Por ello, los resultados deben entenderse como evidencia de asociación y no como prueba de causalidad.

G. Pregunta de investigación

La pregunta de investigación planteada es:

¿Existe relación entre el nivel de estrés percibido y la calidad del sueño en los participantes del Sleep Health and Lifestyle Dataset?

Esta pregunta es coherente con la información disponible, ya que ambas variables se encuentran medidas para todos los participantes y pueden analizarse mediante una técnica de asociación.

H. Aplicación de una técnica bioestadística

Para responder la pregunta se utilizó como técnica principal la correlación de Spearman. Esta prueba es apropiada porque el nivel de estrés y la calidad del sueño son escalas numéricas discretas, con valores acotados, y no es necesario asumir una distribución normal estricta.

I. Interpretación y discusión de resultados

Los resultados muestran que la muestra está integrada por 374 participantes adultos con información completa sobre variables de sueño, estrés, actividad física e indicadores fisiológicos. La distribución por sexo es equilibrada, lo cual mejora la descripción general de la muestra, aunque no garantiza representatividad poblacional. Además, la mayoría de participantes se ubica en la categoría de IMC Normal, pero existe un grupo considerable con sobrepeso, aspecto relevante porque el estado nutricional puede relacionarse con trastornos del sueño.

Desde el análisis descriptivo, la duración promedio del sueño fue de 7.13 horas. Este valor sugiere que, en conjunto, la muestra reporta una duración cercana a rangos habituales de descanso adulto. Sin embargo, el mínimo observado indica que existen participantes con menor duración de sueño, lo cual puede tener importancia sanitaria si se interpreta como posible privación de descanso. La calidad promedio del sueño fue de 7.31 puntos, por lo que la muestra no parece concentrarse exclusivamente en mala calidad del sueño, sino en un rango intermedio a favorable.

El hallazgo principal del análisis es la relación inversa entre el nivel de estrés y la calidad del sueño. La correlación de Spearman indicó una asociación muy fuerte y inversa o negativa, con un valor p <0.001. Esto significa que, dentro de esta base, los participantes con mayores puntuaciones de estrés tienden a reportar menor calidad del sueño. Este resultado es coherente con el gráfico de dispersión, donde la tendencia general es descendente.

La regresión lineal múltiple fortalece la interpretación porque evalúa el efecto del estrés considerando simultáneamente edad y actividad física. El coeficiente de estrés fue -0.579, lo que indica que el aumento de un punto en estrés se asocia con una reducción promedio en la calidad del sueño, manteniendo constantes las variables de ajuste. El R cuadrado ajustado de 0.839 indica que el modelo explica una proporción relevante de la variabilidad de la calidad del sueño, aunque todavía pueden existir factores no incluidos.

El hallazgo más relevante es que el estrés se mantiene como un factor asociado a la calidad del sueño incluso al ajustar por edad y actividad física. Esto permite plantear que el estrés percibido tiene un papel importante dentro del perfil de salud del sueño de la muestra. Sin embargo, también debe considerarse que la actividad física puede actuar como un factor protector o de ajuste, y que el IMC y los trastornos del sueño pueden modificar la forma en que se experimenta el descanso.

No se puede establecer causalidad. El diseño transversal impide determinar si el estrés conduce a mala calidad del sueño, si dormir mal aumenta el estrés, o si ambas condiciones están influidas por otros factores no observados, como carga laboral, turnos nocturnos, consumo de cafeína, ansiedad, enfermedades crónicas o uso de medicamentos. Por ello, las conclusiones deben limitarse a asociaciones estadísticas observadas en la base analizada.

Otra limitación importante es la naturaleza secundaria de la base. Algunas variables pueden depender del autorreporte, lo que introduce posible sesgo de medición. Además, la distribución de ocupaciones no es homogénea: algunas profesiones tienen muchos participantes y otras tienen muy pocos. Esto reduce la posibilidad de hacer inferencias firmes por ocupación y limita la generalización hacia otros grupos poblacionales.

En síntesis, los resultados son útiles para describir el patrón de asociación entre estrés y calidad del sueño en esta muestra. También sirven como base para formular hipótesis futuras. Para confirmar causalidad sería necesario un diseño longitudinal, con seguimiento temporal, medición repetida del sueño y control de variables clínicas, psicológicas y laborales.
